🔍 Vertex AI Search vs Grounding with Google Search

GCP에서 Gemini에 "검색 기반 근거"를 붙이는 두 가지 방법 비교

한 줄 요약

내부/사설 데이터

Vertex AI Search

내 문서·웹사이트·DB를 데이터 스토어에 색인해 두고, 그 안에서 검색해 답하게 하는 엔터프라이즈 RAG/검색 서비스입니다.

공개 웹

Grounding with Google Search

Gemini 호출 시 구글 검색 도구를 켜기만 하면 모델이 필요할 때 직접 검색해 최신 웹 정보로 답하는 내장 기능입니다.

어떤 걸 선택할까?

✅ Vertex AI Search를 고르세요

  • 사내 문서·정책·제품 매뉴얼 기반 Q&A
  • 권한별로 보여줄 문서를 통제해야 할 때
  • 정확한 원문 인용과 도메인 한정 검색이 중요할 때
  • 특정 사이트(내 도메인)만 검색 범위로 제한하고 싶을 때

✅ Grounding with Google Search를 고르세요

  • 뉴스·날씨·시세 등 실시간 공개 정보가 필요할 때
  • 인프라 구축 없이 빠르게 최신성 확보
  • 일반 상식·세상 지식 보강 챗봇
  • 프로토타입·튜토리얼
💡 둘을 함께 쓸 수도 있습니다. 사내 지식은 Vertex AI Search, 외부 최신 정보는 Google Search Grounding으로 나누어 라우팅하는 구성이 흔합니다. 단, 모델·SDK 버전에 따라 한 요청에 여러 검색 도구를 동시에 쓰는 데 제약이 있을 수 있어, 모드를 분리해 선택하게 하는 방식이 안전합니다.

코드 예시 (LangChain + ChatGoogleGenerativeAI)

Grounding with Google Search

model = ChatGoogleGenerativeAI(
    model="gemini-2.5-flash", vertexai=True)
model = model.bind_tools(
    [{"google_search": {}}])

Vertex AI Search (데이터 스토어 연결)

datastore = ("projects/PROJ/locations/global/"
  "collections/default_collection/"
  "dataStores/DATASTORE_ID")
model = model.bind_tools([{
  "retrieval": {"vertex_ai_search":
    {"datastore": datastore}}}])

이 프로젝트(app.py)와의 관계

모드종류비고
Vertex AI GroundingGrounding with Google Search이미 구현됨. Gemini 전용
Custom SearchProgrammable Search Engine(Custom Search JSON API)이미 구현됨. google_cse_search 도구, Ollama에서도 사용 가능
Vertex AI Search사설 데이터 검색(RAG)아직 미구현. 데이터 스토어를 만든 뒤 위 retrieval 도구로 추가 가능
